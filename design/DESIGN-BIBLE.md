# Joanna Portfolio — Design Bible

> Status: v0.1 — Exploration
> Last updated: October 2026

---

# 1. Purpose

This document is the source of truth for the visual direction, interaction
principles, and design decisions for Joanna's personal portfolio.

The website should not feel like a generic developer portfolio or a template.

It should feel personal, thoughtfully designed, playful, and slightly
unexpected while remaining clear and professional.

This document will evolve as individual pages are designed.

---

# 2. Core Design Idea

## Clean at first glance. Playful when you explore.

The website should initially feel:

- clean
- editorial
- calm
- intentional
- professional

As the visitor interacts with it, more personality should gradually appear
through motion, small visual details, and unexpected interactions.

The website should reward curiosity rather than immediately showing every
creative element at once.

### Current personality keywords

- Curious
- Playful
- Editorial
- Personal
- Tactile
- Soft
- Unexpected

### Deeper conceptual direction

Current working idea:

**Curiosity → Collect → Make → Discover**

This is a design philosophy, not necessarily website copy.

Do not force this phrase into the interface unless it eventually feels natural.

---

# 3. Design Principle

## Work is clear. Personality can be weird.

Professional content should remain easy to understand.

Projects should still look like projects.
Navigation should still be navigation.
Resume information should remain easy to find.

Personality should come from:

- interaction
- typography
- motion
- illustration
- small objects
- the dog
- handwritten details
- visual surprises

Do not sacrifice usability simply to make the website creative.

---

# 5. Day / Night Philosophy

The website should support Day and Night visual states.

This should feel atmospheric rather than like a standard dark-mode toggle.

## Day

Keywords:

- airy
- curious
- soft
- fresh
- light
- open

Visual relationship:

**Cool White + Powder Blue + Chocolate**

---

## Night

Keywords:

- quiet
- dreamy
- calm
- slightly magical
- atmospheric

Visual relationship:

**Midnight + Moon Blue + Soft Ice + Cocoa**

---

## Theme Transition

Do not instantly switch CSS colors.

Explore an approximately 0.8–1.2 second atmospheric transition.

Possible changes:

- Powder Blue gradually deepens
- typography changes tone
- background atmosphere darkens
- small stars become visible
- handwritten elements subtly glow
- dog lighting changes
- visual elements transition smoothly

The transition itself should feel like part of the experience.

Status: Exploring

---

## Editorial Serif

Used for:

- Joanna Lei
- major page titles

- selected project titles

luxury-fashion oriented.

---

## Sans Serif

Used for:

- navigation
- body text
- project information
- metadata
- buttons
- resume content

---

## Handwriting

Used very sparingly.

Possible uses:

- tiny observations
- arrows
- stars
- notes
- interaction hints
- playful comments

Handwriting belongs to the personality layer.

It should never be used for important long-form information.

# 8. Dog Character

The user's real dog is currently the strongest candidate for the recurring
personal character.

The dog should NOT become the entire theme of the website.

It should feel like a character that lives inside Joanna's digital world.

---

## Important Visual Characteristics

Preserve:

- chocolate-brown coat
- white facial stripe
- white muzzle
- white chest
- floppy ears
- curious sideways-looking expression
- relaxed personality

Avoid turning the dog into a generic smiling cartoon dog.

The expression and personality are important.

---

## Current Visual Direction

Preferred homepage representation:

**Minimal soft 3D**

Possible secondary representation:

**Editorial doodle / line illustration**

These may coexist.

For example:

- 3D dog on Homepage
- doodle dog in small notes or Easter eggs

---

## Dog Interaction Ideas

Exploratory:

### Idle
Occasional subtle blink.

### Cursor movement
Eyes subtly follow the cursor.

### Hover
Very small ear or head response.

### Long idle
Possible small tail movement.

### Night Mode
Lighting changes subtly.

The dog does not need to dramatically "go to sleep."

---

## Important Rule

**The dog is a dog, not a button.**

Do NOT:

- put "Projects" on the dog's tag
- make the dog hold the Resume
- use body parts as navigation
- force the dog to explain content
- turn every page into a dog-themed page

The dog exists primarily for personality and emotional continuity.

---

# 10. Layout Philosophy

Avoid building the entire website from cards.

## Rule

**No card unless the content genuinely needs a container.**

Prefer hierarchy through:

- typography
- scale
- spacing
- position
- color
- motion
- composition

rather than:

- rounded rectangle
- shadow
- image
- text
- repeat

---

# 11. Motion Philosophy

Motion is an important part of the identity.

However:

## Nothing moves just because it can.

Every animation should serve at least one purpose:

- Respond
- Guide
- Reveal
- Express curiosity
- Create atmosphere
- Surprise

---

## Interaction Goal

The desired visitor experience:

### First glance
"This is clean."

### Move the mouse
"Oh?"

### Explore for several seconds
"There are little details here."

### Interact further
"This website has personality."

Creativity should reveal itself gradually.

# 13. Motion Accessibility

Support:

`prefers-reduced-motion`

When enabled:

- remove unnecessary parallax
- disable cursor-following effects where appropriate
- simplify theme transitions
- preserve all functionality

Motion must never be required to understand the website.

## Visual

- beige-dominant portfolio
- generic cream lifestyle aesthetic
- excessive rounded cards
- excessive shadows
- generic SaaS gradients
- purple/blue developer gradients
- excessive glassmorphism
- excessive doodles
- huge dark Chocolate Day Mode sections

- everything being 3D
- everything being cute

- animations with no purpose
- excessive scroll hijacking
- distracting custom cursors
- constant motion
- interactions that hide essential information

- turning every project into an object
- making the dog responsible for navigation
- choosing trends only because they are trendy

# 24. Design Workflow

Generate and discuss several possible directions.

## 3. Document
Update this Design Bible and create the page specification.

## 4. Prototype
Test the idea visually or in-browser.

## 5. Lock
Mark major decisions as approved.

## 6. Build
Implement according to the approved specification.

# 29. Reminder

The goal is not to make the most visually complicated portfolio possible.

The goal is to create something that feels unmistakably personal while still
being easy to use.

When choosing between adding another decorative element and improving a
meaningful interaction, prefer the meaningful interaction.

When choosing between following a trend and maintaining the site's personality,
prefer personality.

When uncertain:

**Keep the work clear and put the surprise in the details.**
